# SkyConnect - College Project Demo Guide

## 🎯 **Project Overview**
SkyConnect is a real-time video conferencing platform built with MERN stack and WebRTC technology.

## 🚀 **How to Run**
1. Backend: `cd backend && npm run dev` (Port 8000)
2. Frontend: `cd frontend && npm start` (Port 3000)
3. Open: http://localhost:3000

## 🎮 **Demo Features**

### 1. **Landing Page**
- Click "Create Room" → Generates unique room ID
- Enter room ID → Join existing room
- Quick Meeting option

### 2. **Video Call Features**
- Real-time video/audio calls
- Camera on/off toggle
- Microphone mute/unmute
- Screen sharing capability
- Real-time text chat
- End call functionality

### 3. **Technical Implementation**
- **Frontend**: React.js + Material-UI
- **Backend**: Node.js + Express.js + Socket.io
- **Database**: MongoDB
- **WebRTC**: Peer-to-peer video streaming
- **Real-time**: Socket.io for signaling
